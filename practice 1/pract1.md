# Практическая работа 1.

Командная строка с GUI на Python (tkinter), файл `main.py`.

- **Этап 1:** REPL, парсер с кавычками, команды `ls`, `cd`, `exit`.
- **Этап 2:** параметры `--vfs`, `--scripts`, `--config`, INI-конфиг, стартовый скрипт, `conf-dump`.
- **Этап 3:** VFS из XML (base64 для двоичных данных) в памяти, команды `ls`, `cd`, `pwd`.

Запуск: `py main.py [--vfs vfs/deep.xml] [--scripts script/test_all.txt] [--config config.ini]`

Тесты: `tests/*.bat`, `script/*.txt`, примеры VFS в `vfs/`.
