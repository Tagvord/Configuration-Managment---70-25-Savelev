# Практическая работа 3. Ассемблер и интерпретатор учебной виртуальной машины (УВМ)

Ассемблер переводит программу из текстового CSV-формата в промежуточное
представление (список словарей), а затем в машинный код УВМ.
Сторонние библиотеки не нужны, только Python 3.11+.

## Запуск

Из папки `practice 3`:

```sh
python assembler.py examples/spec.csv out/spec.bin --test
```

| Аргумент | Смысл |
|---|---|
| `source` | исходный файл с текстом программы (CSV) |
| `output` | путь к двоичному файлу-результату |
| `-t`, `--test` | режим тестирования: вывести байты каждой команды |

Ассемблер всегда сообщает размер двоичного файла в байтах.

Демонстрации в Windows: `tests\stage2_bytes.bat`, `tests\errors.bat`,
автоматические проверки — `tests\unit.bat` (или `python -m unittest discover -s tests -v`).

## Язык ассемблера

Программа — CSV-файл в UTF-8, одна команда на строку: `команда,операнд`.

* Регистр мнемоники не важен, пробелы вокруг полей игнорируются.
* Строка, первое поле которой начинается с `#`, — комментарий. Пустые строки пропускаются.
* Операнд — неотрицательное целое: `668`, `0x29C`, `0b1010`.

| Команда | Код A | Поле B (биты) | Диапазон B | Действие |
|---|---|---|---|---|
| `load,C` | 119 | константа, 7–21 | 0..32767 | положить C на стек |
| `read,S` | 16 | смещение, 7–20 | 0..16383 | снять адрес X со стека, положить `mem[X + S]` |
| `write,M` | 89 | адрес, 7–18 | 0..4095 | снять значение со стека, записать в `mem[M]` |
| `eq,M` | 38 | адрес, 7–18 | 0..4095 | снять X со стека, положить `1`, если `X == mem[M]`, иначе `0` |

Каждая команда занимает 3 байта.

Пример (`examples/spec.csv`) — тесты из спецификации:

```csv
load,668
read,786
write,687
eq,252
```

Вывод в режиме тестирования совпадает с байтами из спецификации:

```
load,668    -> 0x77, 0x4E, 0x01
read,786    -> 0x10, 0x89, 0x01
write,687   -> 0xD9, 0x57, 0x01
eq,252      -> 0x26, 0x7E, 0x00
Команд: 4. Размер файла out/spec.bin: 12 байт
```

Ошибки (неизвестная команда, нет операнда, не число, выход за диапазон поля B)
сообщаются с номером строки; примеры — в `examples/errors/`.

## Промежуточное представление

Список словарей, по одному на команду:

```python
{"name": "load", "A": 119, "B": 668, "line": 1}
```

`line` — номер строки исходного файла, нужен для сообщений об ошибках.

## Машинный код

Команда собирается в 24-битное слово `A | B << 7` и записывается тремя байтами
от младшего к старшему (little-endian). Пример для `load,668`:

```
A = 119 = 0b1110111, B = 668
слово = 119 + 668 * 128 = 85623 = 0x014E77
байты: 0x77, 0x4E, 0x01
```
